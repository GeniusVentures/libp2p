<objective>
Implement `PnetProtectedConnection` — a `RawConnection` decorator establishing the pnet PSK boundary (PNET-01): lazy per-direction 24-byte nonce exchange, then XSalsa20 encryption of everything in both directions, byte-exact with go-libp2p's psk_conn.go semantics.

Purpose: This is the component enforcing "only PSK-holding peers get usable connections" (PNET-03): a wrong-key peer decrypts garbage and multiselect fails naturally. It is the wrap-point mandated by the carry-forward decision — RawConnection wrapped *before* Upgrader/multiselect, never a SecurityAdaptor.

Output: `pnet_protected_connection.{hpp,cpp}` added to `p2p_pnet`, plus test target `pnet_protected_connection_test` proving round-trip, mismatch rejection, and wire-leak absence (TEST-02).
</objective>

Implement class libp2p::security::pnet::PnetProtectedConnection : public connection::RawConnection, public std::enable_shared_from_this<PnetProtectedConnection> in namespace libp2p::security::pnet (header guard LIBP2P_SECURITY_PNET_PNET_PROTECTED_CONNECTION_HPP). Constructor: PnetProtectedConnection(std::shared_ptr<connection::RawConnection> inner, std::shared_ptr<const Psk> psk, std::shared_ptr<basic::Scheduler> scheduler). Members: inner_, psk_, scheduler_, std::optional<crypto::xsalsa20::XSalsa20Stream> write_stream_ and read_stream_ (two INDEPENDENT per-direction states — Pattern 1; never shared across connections or directions), static logger via log::createLogger("PnetConn") if needed for failure observability — NEVER logging key bytes (D-06).

Public overrides, porting go-libp2p psk_conn.go lazily per direction:
1. writeSome(gsl::span<const uint8_t> in, size_t bytes, Writer::WriteCallbackFunc cb): if !write_stream_ — generateNonce() (failure → deferWriteCallback(error)); write the 24-byte nonce IN THE CLEAR first via inner_->writeSome with the nonce held in a std::make_shared-owned buffer captured in the completion lambda (Pitfall 2); on nonce-write success initialize write_stream_ from psk_->span() + nonce, then proceed. Encrypt path: copy in.first(bytes) into a std::make_shared<std::vector<uint8_t>> (const input span cannot be encrypted in place and the buffer must outlive the async inner write — Pitfall 2), crypt() it with write_stream_, delegate inner_->writeSome, completion routed through deferWriteCallback — never call cb inline from the inner callback.
2. read and readSome: if !read_stream_ — first issue inner_->read(nonce_buf, 24, cb_chain) using the EXACT-min(out.size(), bytes) variant, NEVER readSome, for the peer nonce (Pitfall 3); on success initialize read_stream_. Then delegate inner_->read/readSome; in the completion, crypt exactly the n bytes actually read (decrypt n, where n is the result value — never the full buffer) and deliver via deferReadCallback.
3. Reading note: because decrypt is in-place XOR, the caller's output buffer must be crypt()-ed after the inner read completes but before the deferred callback fires — do the XOR inside the completion lambda, on exactly result.value() bytes.
4. close / closeHonoringTimeout / isInitiator / localMultiaddr / remoteMultiaddr: pure delegation to inner_.
5. deferReadCallback / deferWriteCallback overrides: route through scheduler_ (Phase 1 carry-forward reentrancy rule) — mirror how existing connection implementations in src/connection/ and upgrader code defer via scheduler_->schedule; check src/transport/impl/ or an existing connection impl for the established defer spelling and copy it.

Sizing: keep the class a decorator only — no negotiation logic, no multiselect knowledge, no error invention beyond PnetError values already declared in Plan 02 (nonce gen/read failures map to PNET_NONCE_GENERATION_FAILED / PNET_NONCE_READ_FAILED).

CMake: add pnet_protected_connection.cpp to the p2p_pnet source list; add p2p_crypto_xsalsa20 and (if not already) the p2p_connection-level interface target that raw_connection.hpp lives in — check sibling security leaf libs (e.g. src/security/plaintext/CMakeLists.txt) for the conventional link names; also link whatever target provides basic::Scheduler if it is a concrete lib (not just a header).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Inner (network) connection ↔ PnetProtectedConnection | Ciphertext (after 24B cleartext nonce) crosses here from untrusted peers |
| PSK ↔ keystream | Key material feeds XSalsa20Stream; never crosses a log or copy boundary |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-02-09 | Information Disclosure | wrong-PSK peer reaching negotiation | mitigate | Garbage-decrypt property asserted in MismatchedPsk test (PNET-03 emergent; no protocol reject message exists by design) |
